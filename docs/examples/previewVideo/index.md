## API


### `<属性>` Props

| 参数名    | 默认值                     | 描述说明 | 类型    | 必填 |
| :-------- | :------------------------- | :------- | :------ | ---- |
| v-model   | `false`                    | 是否显示 | boolean | 是   |
| watermark | `{ text: "", styles: {} }` | 水印     | object  | 否   |
| poster    | `" "`                      | 封面地址 | string  | 否   |
| url       | `" "`                      | url地址  | string  | 否   |
